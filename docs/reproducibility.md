# YottaFlex Reproducibility & Provenance Guide

This document provides exact instructions, verification hashes, and reproducibility steps for the synthetic data generator and validation engine.

---

## 1. Provenance & Synthetic Data Statement

All records generated by the YottaFlex Employee Lifecycle Orchestrator are **100% synthetic**.
- No confidential, proprietary, or personal data from real corporate systems or employees was utilized.
- Names, emails, serial numbers, and assets were generated deterministically using pseudo-random linear congruential algorithms combined with Python's `Faker` library pinned to seed `20261022`.
- Zero credentials, passwords, or live API tokens are used or generated.

## 4. Reproducibility Verification Commands

### Step 1: Generate Starter Dataset
```powershell
python -m backend.generator.cli --scale starter --seed 20261022 --output data/starter
```

### Step 2: Generate Full Dataset
```powershell
python -m backend.generator.cli --scale full --seed 20261022 --output data/full
```

### Step 3: Run Deterministic Bit-for-Bit Checksum Verification
To verify that repeated generation produces identical SHA-256 hashes:
```powershell
# Generate to two distinct directories
python -m backend.generator.cli --scale full --seed 20261022 --output data/test_run_1
python -m backend.generator.cli --scale full --seed 20261022 --output data/test_run_2

# Compare manifests and file checksums
python -c "
import json
m1 = json.load(open('data/test_run_1/manifest.json'))['file_checksums']
m2 = json.load(open('data/test_run_2/manifest.json'))['file_checksums']
for f in sorted(m1.keys()):
    assert m1[f] == m2[f], f'Mismatch in {f}'
print('SUCCESS: All 20 output tables and artifacts match 100% bit-for-bit!')
"
```

## 5. Machine-Readable Manifests

Every generation run produces `manifest.json` in the output directory containing:
- Seed and scale configuration
- Reference evaluation date
- Exact row counts per entity
- SHA-256 checksums for all exported files (excluding `manifest.json` itself to avoid circular hash self-reference)
- Precision, recall, and F1 evaluation metrics against ground truth.
